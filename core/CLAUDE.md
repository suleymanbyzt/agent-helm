## Advisor loop

For **L2/L3** work, the full loop:

1. **Before proposing:** consult the advisor about the request and the
   intended approach.
2. **Report to the user** in the 3-line format (Problem / Plan / Risk /
   Question) — short, plain language. Wait for approval.
3. **After approval:** get implementation guidance from the advisor, then
   write the code.
4. **When the code is done:** request a final advisor review — open issues,
   gaps, anything missed.
5. **Only when both of you agree** the work is sound, report to the user:
   Done / Verified / Recorded — short, no detail dump. The user's word
   closes the task.

For **L1** work: steps 1 and 3 are optional, but steps 4-5 are not — every
finished task gets the final advisor review, and the user hears about it
only after both agents agree. **L0** skips the advisor entirely.

If you and the advisor disagree, never pick a side silently: surface the
disagreement to the user as one short question with both options.
